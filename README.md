### 🛠️ Features & Animations
1. **Interactive 3D WebGL Canvas Layer (Three.js)**:
   - Dynamic undulating particle terrain responding to mouse cursor and 3D scroll depth.
   - Central Gyroscopic 3D Holographic Polyhedron with interactive orbital rings and camera fly-through.
2. **3D Tilt Cards**:
   - Realistic physics-based perspective cards with specular glare tracking mouse coordinates.
3. **Cyber Web Audio Synthesizer**:
   - Zero external audio files required — generates real-time high-tech futuristic click and confirmation sound effects via Web Audio API (with instant mute/unmute toggle).
4. **Interactive Cyber Terminal HUD**:
   - Functional command simulator supporting `help`, `whoami`, `projects`, `skills`, `contact`, `github`, `matrix` (with particle fireworks), and `clear`.
5. **Decryption Text Scrambler**:
   - Cyberpunk letter scrambler animation on headlines and navigation elements.
6. **Dark & Grey High-End Aesthetic**:
   - Obsidian, graphite, gunmetal grey, and titanium silver palette with glassmorphism and ambient spotlight tracking.

### 💻 Local Development

```bash
# Install dependencies
npm install

# Run Vite dev server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deploy to Vercel (Fast & Easy in 2 minutes)

### Option 1: Via Vercel CLI
```bash
npx vercel
```
Follow the simple prompts (select default settings: framework `Vite`, build command `npm run build`, output directory `dist`).

### Option 2: Via GitHub + Vercel Dashboard
1. Push this folder to your GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: complete 3D dark cyber portfolio"
   git branch -M main
   git remote add origin https://github.com/jitin-s/<repo-name>.git
   git push -u origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new), select your repo, and click **Deploy**! Vercel will automatically build and publish it live on a fast global edge network.
